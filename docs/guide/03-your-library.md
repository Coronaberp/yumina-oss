# Your Library

Your library is your personal collection of worlds you've played or saved.

## Games tab

The default tab shows all worlds in your library. Each card shows the cover, title, an update indicator (blue dot), and a heart if you've favorited it.

**Card actions on hover:**
- Continue playing
- Edit (copies to your projects)
- Export as JSON
- Remove from library

**Sorting:** Alphabetical, Recent (last played), or Added (when you saved it). Favorited worlds always pin to the top regardless of sort order.

**Search:** Filter your library by name with the search bar.

## Detail panel

Click any world card to expand a detail panel on the right with:
- Cover image, title, creator info
- Play / Edit / Room buttons
- Stats: last played, creation date, token usage
- Description, tags, announcements

## Session management

Click **Play** to open the session picker. You'll see all your sessions for that world with message count and last activity. You can:
- Pick an existing session to continue
- Create a new session with **+ New Session**
- Multi-language worlds show language tabs at the top

Sessions are fully independent -- different story states, different histories.

## Export and import chats

Open **Export** in the VN menu, **Export / import chat** in the chat header, or the library's session export action. Choose **Transcript** for messages, profile pictures and attachments, or **Full save** to include the world, progress, checkpoints and memory. Full saves with many images can be large.

The download is one HTML file. Open it in a browser to search, filter by speaker or reply type, sort by time, jump to a turn, or print. Profile pictures and attachments work offline. Filters leave the embedded JSON intact; **Download JSON** saves that same data separately.

To restore an export, choose its HTML or JSON file in the export/import dialog and select **Import as a new session**. A full save creates a separate private card and restores its progress. A transcript creates a session on its original accessible card with the card's initial state. StoryHaven facts travel as continuity notes. The original session remains independent.

## My Projects

The second tab shows worlds you've created or copied, split into In Development (drafts) and Published. See the [Creator Guide](/creator/) for details.

## Assets

The third tab manages your uploaded files -- images (PNG, JPG, WebP, SVG), audio (MP3, WAV, OGG), and fonts (TTF, OTF, WOFF). Organized in a folder tree with drag-and-drop. The library shows current storage use; account storage is not capped by plan.

## Bundles

The fourth tab shows resource packs you've collected -- packaged asset sets from creators. Mostly relevant for world creation.
